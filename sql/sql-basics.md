# SQL / Oracle

## Практический опыт
Основная практическая зона — Oracle SQL:
- чтение и анализ больших запросов;
- поиск причин ошибок;
- анализ данных при расследовании интеграционных проблем;
- понимание связей между таблицами.

## Чек-лист подготовки
### Типы SQL
- DDL;
- DML;
- DQL;
- DCL;
- TCL.

### Основные конструкции
- SELECT;
- WHERE;
- GROUP BY;
- HAVING;
- ORDER BY;
- JOIN;
- subquery;
- CTE.

### JOIN
Уметь объяснить:
- INNER JOIN;
- LEFT JOIN;
- RIGHT JOIN;
- FULL OUTER JOIN.

Особенно понимать разницу между INNER и LEFT JOIN и влияние условий в ON/WHERE.

### Агрегатные функции
- COUNT;
- SUM;
- AVG;
- MIN;
- MAX.

### Оконные функции
Понимать OVER(), PARTITION BY, ORDER BY и типовые задачи:
- нумерация строк;
- поиск предыдущей/следующей записи;
- расчёт накопительного значения;
- выбор последней записи в группе.

### Для собеседования
Нужно не только помнить синтаксис, но и уметь объяснить, как SQL используется при расследовании интеграционной проблемы.
