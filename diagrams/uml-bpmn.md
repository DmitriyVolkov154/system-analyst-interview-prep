# BPMN и UML

## BPMN
BPMN удобно использовать для моделирования бизнес-процесса.

Базовые элементы:
- событие;
- задача;
- gateway;
- sequence flow;
- message flow;
- pools/lanes.

Типовая задача: показать, кто выполняет действие, какие есть ветвления, где возникает событие и как проходит процесс.

## UML
UML — набор нотаций для моделирования системы.

Особенно полезны:
- Use Case — кто и какие функции использует;
- Sequence — взаимодействие объектов/систем во времени;
- Activity — последовательность действий и ветвления;
- Class — структура классов/объектов;
- State Machine — состояния объекта и переходы.

## Для системного аналитика
Не нужно рисовать диаграмму ради диаграммы. Выбор нотации зависит от вопроса, который нужно прояснить.

Примеры:
- бизнес-процесс → BPMN;
- взаимодействие систем/API → Sequence;
- состояния заказа → State Machine;
- функциональные возможности и акторы → Use Case.
