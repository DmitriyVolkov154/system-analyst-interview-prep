# System Analyst Interview Prep

Подготовка к собеседованию на позицию системного аналитика.

## Цель
Перейти от текущей роли специалиста с аналитическими задачами к классической роли системного аналитика в команде разработки: требования → проработка решения → интеграции → разработка → тестирование → запуск.

## Текущий фокус
- Требования и их выявление
- REST / SOAP / API
- Интеграции и шина сообщений
- SQL / Oracle
- BPMN / UML
- Архитектурные основы: DDD, CQRS, Event-Driven
- Практика собеседований

## Мой практический опыт
- Анализ инцидентов и проблем в производственных системах
- Работа с бизнес-пользователями и смежными командами
- Подготовка ТЗ
- Тестирование и проверка изменений
- Поддержка интеграций между системами
- Практический SQL в Oracle
- Асинхронная обработка, очереди, статусы, повторная обработка
- Знакомство с REST API, Postman, JSON, HTTP-кодами и токенами

## Важное ограничение
Не выдавать практический коммерческий опыт Kafka за имеющийся. Корректная формулировка: есть практический опыт асинхронной обработки и очередей, Kafka изучается отдельно.

## Ближайшая задача
Подготовиться к технической части интервью и уметь объяснять решения своими словами, а не воспроизводить заученные определения.
